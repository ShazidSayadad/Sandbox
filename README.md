# Sandbox
## Sandbox made with raylib
### 1. Install Prerequisites:
* Windows OS
* Visual Studio 2022 or later (Desktop development with C++ workload)
* Git
* vcpkg 

### 2. Clone the Repository
* ```git clone https://github.com/ShazidSayadad/Sandbox.git```
* ```cd Sandbox```

### 3. Install Raylib Using vcpkg
```vcpkg install raylib:x64-windows```

### 4. Enable vcpkg Integration with Visual Studio (one-time)
```vcpkg integrate install```

### 5. Open the solution file *.sln
### 6. Build and run
